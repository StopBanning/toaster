# Making a video with Toaster

Toaster listens to whatever is playing and writes it out as live [Strudel](https://strudel.cc) code, with visuals
around it. This page is for anyone filming it: how to set it up, how to get the code building up on camera, and how
to take it further in Strudel.

## Set up (two minutes)

- **Where it listens:** the desktop app ([Windows and Mac](https://github.com/StopBanning/toaster/releases)) hears
  your computer's sound. The website ([toaster.locust.lol](https://toaster.locust.lol)) hears a browser tab, the
  microphone or a file. For the cleanest take, play a file (S picks the source).
- **The frame:** L switches to a vertical layout for TikTok, Reels and Shorts. H hides the header and footer, and F
  goes fullscreen.
- **The look:** T changes the theme (white reads well on video). P changes the code's look: dominoes, the handheld
  game, a punchcard, or none. V picks the background and A steps to the next one (the next scene, for example).

## The take

- **Start the song from the very beginning.** Toaster finds the tempo within the first 10 to 20 seconds, then types
  each part in as it hears it: the drums, the bass, the chords. That's your build-up, live.
- **Press D right on the drop.** It marks the drop in the code (`// drop`), and the backgrounds hit with it. B picks a
  drop effect, from an old XP takeover to a blue screen.
- **If the tempo comes out double or half,** tap four beats on Space.
- **If the song's name is wrong,** press E and type it.
- **For a pure visualizer shot,** Z hides the code (it's still written underneath).

## Recording

- **In the app, M records** the window with its sound, no screen recorder needed. On the website, use your own screen
  recorder.
- **J clips** the first two drops of each song on its own.

## Taking it into Strudel

- **O opens the code in strudel.cc**, where it plays.
- **To build it up the way live coders do,** put a `_` in front of every part's name except the drums (`_bassline:`,
  `_chords:`), then delete them one at a time and press Ctrl+Enter.
- **X exports the song so far** as Strudel code and MIDI.
- **What to expect:** Toaster writes the drums, the bass line and the chords. It won't transcribe the vocals (at most it guesses a
  few lead notes), so adding the hook by hand is a great moment on camera.
